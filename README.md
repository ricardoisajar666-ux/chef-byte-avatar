# Chef Byte - Avatar Interactivo

## Descripción
Avatar interactivo de "Chef Byte", un asistente culinario digital en forma de cuchara mágica que enseña a cocinar platos de diferentes culturas del mundo.

## Características
- Avatar animado con expresiones faciales
- Recetas interactivas de diferentes países
- Datos curiosos sobre la ciencia culinaria
- Interfaz amigable y educativa
- Diseño responsive para móviles

## Tecnologías Utilizadas
- HTML5
- CSS3 (con animaciones)
- JavaScript vanilla

## Cómo Usar
1. Abre el archivo `index.html` en tu navegador
2. Haz clic en los botones de recetas para ver las instrucciones
3. Explora los datos curiosos sobre la ciencia de la cocina
4. ¡Diviértete aprendiendo a cocinar!
